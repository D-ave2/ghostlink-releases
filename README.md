# GHOSTLINK Releases

Official public distribution home for GHOSTLINK // INFINITY.

## Windows x64

After the tiny command registration step on a target PC, the only command required is:

```powershell
DOWNLOAD GHOSTLINK
```

That command checks the latest public GHOSTLINK release, downloads the Windows bootstrap, verifies its SHA-256 checksum, installs or repairs the required Windows components and EQ profiles, then launches GHOSTLINK.

Current release channel: **stable / Windows x64**

The current development Windows build is not yet code-signed.
